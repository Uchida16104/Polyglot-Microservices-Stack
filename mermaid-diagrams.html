sequenceDiagram actor U as User participant FE as SvelteKit Frontend participant GW as Laravel Gateway participant DB as CockroachDB participant RD as Redis rect rgb(20,20,35) Note over U,RD: LOGIN FLOW U->>FE: Submit credentials FE->>GW: POST /api/auth/login GW->>DB: SELECT user WHERE email=?
